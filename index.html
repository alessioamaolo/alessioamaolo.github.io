Research Interests

I am interested in bounding nanophotonic device performance. I am currently working on developing new inverse design methods by leveraging information from fundamental limits. I am advised by Prof. Alejandro Rodriguez. This website primarily exists to host my CV and notes.

Code

Check out my GitHub. Packages:
  • I am a core contributor / maintainer for Dolphindes, a recent library for calculation of photonic device performance bounds. Most of my newer publications use Dolphindes to some extent, and I use it as a repository for examples reproducing my results.
  • I am working on Fluxmax, a highly parallelizable (via JAX SPMD distributed array sharding) optimization library for designing photonic metasurfaces for near-field radiative heat transfer (NFRHT). It is still a bit sparse but there will be a lot more code and examples soon.
Other Code:
  • Photonic Gearbox: this small package implements the Eigenvalue-accelerated LDOS optimization in 2D polar coordinates to design compact ultra-high quality cavities. (Repo is still not public but will be soon)
